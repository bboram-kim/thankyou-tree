# 트리 주인 식별

## Decisions

- 트리 주인은 로그인하지 않습니다. 트리를 만들 때 주인 링크를 하나 받고, 그 링크를 가진 사람을 트리 주인으로 봅니다.
- 트리 하나에는 링크가 두 개 있습니다. 공유 링크는 트리를 보고 오너먼트를 다는 용도이고, 주인 링크는 감사 메시지와 보낸 사람 이름을 읽는 용도입니다.
- 공유 링크로는 주인 링크를 알아낼 수 없어야 하고, 주인 링크는 추측할 수 없어야 합니다.
- 주인만 할 수 있는 일(메시지 읽기와 이후 주인 설정)은 모두 주인 링크로 판별합니다.

## Boundaries

- 주인 링크를 잃어버렸을 때 되찾는 방법은 없습니다. 링크를 받은 사람은 누구든 주인과 같은 권한을 가집니다.
- 방문자도 로그인하지 않습니다. 이 결정은 방문자 식별 방식을 정하지 않습니다.

## Why

동료끼리 하는 소소한 연말 이벤트라서, 가입이나 로그인 없이 바로 트리를 만들고 써 보는 쪽을 택했습니다. 링크 분실이나 실수로 공유하는 위험은 링크를 받을 때 따로 저장하라는 안내로 받아들입니다.

## Reconsider when

- 주인 링크를 잃어버려 메시지를 못 본다는 일이 실제로 반복될 때
- 한 사람이 여러 기기나 여러 트리를 관리해야 하는 요구가 생길 때

## Still-rejected alternatives

- 이메일 가입과 로그인으로 주인을 식별 — 기기를 바꿔도 안전하지만 가입, 로그인 화면과 인증 설정이 더해져 바로 써 보기 어렵습니다. 위 재검토 조건이 생기면 다시 봅니다.

# 트리의 날씨와 낮밤

## Decisions

- 트리 지역은 트리를 만들 때 브라우저 위치 권한으로 한 번 받습니다. 위치는 브라우저에서 기상청 5km 격자 번호로 바꾸고, 저장하는 것은 격자 번호(`ty_trees.grid_nx`, `grid_ny`)뿐입니다. 위경도 원값은 저장하지 않고, 방문자 화면과 그 응답에도 격자보다 정밀한 위치를 내보내지 않습니다.
- 위치를 거절했거나, 일정 시간 안에 받지 못했거나, 기상청 격자 밖(국외 등)이면 트리 만들기를 막지 않고 지역을 서울로 둡니다. 만든 직후 링크 화면에 서울 날씨로 보인다는 안내를 보여 줍니다. 위치 기능 전에 만든 트리도 서울입니다. 트리를 만든 뒤 지역을 바꾸는 기능은 없습니다.
- 날씨는 공공데이터포털의 기상청 단기예보 조회서비스 중 초단기예보(`getUltraSrtFcst`)로 가져옵니다. 인증키 `DATA_GO_KR_SERVICE_KEY`는 서버에서만 읽습니다. 같은 격자의 날씨는 30분 동안 다시 쓰고, 어떤 이유로든 가져오지 못하면 맑음으로 그립니다.
- 트리 날씨는 맑음, 흐림, 비, 눈 네 가지입니다. 강수형태 비·빗방울은 비, 눈·비/눈·눈날림·빗방울눈날림은 눈입니다. 강수가 없으면 하늘상태 구름많음·흐림은 흐림, 맑음은 맑음입니다.
- 낮밤은 트리 지역의 오늘(한국 날짜) 일출 이후 일몰 전이면 낮, 그 밖은 밤입니다. 일출·일몰은 별도 API 없이 격자 중심 위치와 날짜로 계산합니다. 해질녘 단계는 없습니다.
- 날씨와 낮밤은 페이지를 열 때 한 번 정합니다. 날씨를 글로 표시하지 않고 장면으로만 보여 줍니다.
- 트리 장면 배경은 "안개와 역광" 연출입니다(채도 낮은 하늘, 트리 뒤로 번지는 빛, 땅 안개, 필름 질감, 비네팅). 트리 모양은 그대로 두고 장면의 빛에 맞춘 색 보정만 합니다. 날씨·낮밤 8가지 상태의 색 값은 `components/tree-scene.tsx`에 있습니다.
- 밤에는 트리 장면만이 아니라 트리에 딸린 화면 전체(방문자 트리, 오너먼트 달기 흐름, 주인 화면과 메시지 보기)가 프로젝트의 기존 다크 토큰으로 바뀝니다. 새 색을 만들지 않습니다. 트리 만들기(홈)는 트리 지역이 없으므로 항상 밝은 화면입니다.
- 움직임 줄이기(`prefers-reduced-motion`)를 켠 사용자에게는 비와 눈이 멈춘 채로 보입니다.

## Boundaries

- 트리는 주인의 장소를 담습니다. 방문자 자신의 위치나 시간대는 반영하지 않습니다.
- 밤 전환은 주인 지역의 시간으로만 정합니다. 사용자가 다크 모드를 직접 켜고 끄는 설정은 없습니다.
- 기온, 미세먼지, 바람 같은 다른 날씨 요소는 다루지 않습니다.
- 위치 권한은 HTTPS에서만 동작합니다. 다른 기기에서 HTTP 주소로 열면 항상 서울로 저장됩니다.

## Why

링크를 연 누구나 트리를 보므로, 주인의 정확한 위치가 남거나 새지 않도록 격자 번호만 남깁니다. 위치를 못 받아도 만들기를 막지 않는 것은 방문자에게 링크를 보내기까지의 걸림돌을 늘리지 않기 위해서입니다. 시·도 선택보다 위치 권한을 쓰는 이유는 주인 동네를 더 정확히 담기 위해서입니다.

초단기예보는 한 번의 조회로 하늘상태와 강수형태를 함께 받을 수 있고, 30분 단위로 발표되며, 개발계정 하루 호출 한도가 있어서 같은 격자를 30분 동안 다시 씁니다. 비/눈 섞임과 눈날림을 눈으로 보는 것은 크리스마스 트리 분위기에 맞추기 위해서입니다.

밤에 화면 전체를 어둡게 하는 것은 밤에 링크를 열었을 때 화면 전체가 주인의 밤처럼 느껴지게 하기 위해서입니다.

## Still-rejected alternatives

- 지역을 시·도 목록에서 고르기: 주인 동네를 정확히 담지 못합니다.
- 언덕, 집, 구름 같은 도형으로 배경 그리기: 촌스럽다는 판단으로 버렸습니다. "깊고 영화 같은 빛" 방향의 세 안(안개와 역광, 빛줄기, 먼 도시의 보케) 중 안개와 역광을 골랐습니다.
- 밤에 트리 장면만 어둡게 하기, 해질녘 단계를 더하기: 화면 전체를 어둡게 하는 안과 비교한 뒤 고르지 않았습니다.

## Evidence worth preserving

- 승인된 시각 기준은 `docs/specs/tree-weather-daynight/prototype.html`이었고, 폴더를 정리한 뒤에는 Git 커밋 `1b9048f`에 남아 있습니다. 구현은 8가지 상태를 이 프로토타입과 나란히 비교해 맞췄습니다.
- 기상청 실제 응답으로 확인한 코드: `SKY` 1·3·4, `PTY` 0. 격자 변환식은 서울(60, 127), 부산(98, 76)으로 확인했습니다.
